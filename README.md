# מחשבון עסקאות פליפ נדל״ן

אפליקציית ווב לניתוח עסקאות פליפ נדל״ן בארה״ב: תקציב אישי, אפשרויות מימון, עלות שיפוץ לפי קטגוריה (בסיסי/מתקדם/פרימיום), עלויות החזקה ומכירה, הערכת מס, והשוואה למכירות דומות (Comps) לחישוב שווי מכירה משוער (ARV).

## הרצה

```bash
npm install
npm run dev
```

## מקורות מידע (Comps)

הגרסה הנוכחית מסתמכת על הזנה ידנית או ייבוא CSV של עסקאות דומות שנסגרו לאחרונה באזור (כתובת, מחיר מכירה, שטח, תאריך). סריקה אוטומטית של אתרי נדל״ן/פייסבוק לא מומשה בכוונה — רוב האתרים אוסרים scraping בתנאי השימוש והנתונים משתנים ללא אזהרה. כדי לחבר מקור נתונים חי בעתיד, האפשרות הפשוטה ביותר היא אינטגרציה עם API בתשלום (למשל RentCast, ATTOM Data) שמחזיר נתוני מכירות ותיווך רשמיים.

## הבהרה

הערכות המס וההוצאות הן כלליות לצורך תכנון בלבד ואינן מהוות ייעוץ מס, משפטי או פיננסי.
